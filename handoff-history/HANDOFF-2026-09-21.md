## ✅ Working Solutions

- **No-repeat memory** (`stato.viste`): `chiaveVista/chiaveDomanda/chiaveFrase` (7-char hash cached in `_k`), `insiemeViste(tipo)`, `segnaViste`, `segnaVisteGioco` (debounced save 1.2 s),
  `azzeraViste(tipo,contaGiro)`, `pescaNuove`, `pescaNuovePesate(elenco,quante,tipo,chiaveDi,peso)`. Types: `'gd'+lg` quiz questions (Vero o Falso + X e O + Blitz together), `'gf'+lg` quotes
  (Completa + Chi sono io?), `'gm'+lg` Memoria, `'gi'+lg` Impiccato, `'gc'+lg` Cruciverba. A question is marked when it APPEARS. When all have come out the round restarts.
- **Levels weigh, they don't filter:** `pesoDomanda(d,liv)=0.25^|dif-centro|` (centres 1, 2, 3.5): easy = mostly easy questions, hard = mostly hard, but all 5,000 remain reachable.
- **Adaptive question card:** `adattaCard(chiave)` tries `--fs` from min(34, width/32) down to 12 until question, answers and clues all fit (checks scrollHeight/scrollWidth), caches per question, redoes on `resize`.
- **Colour language of the games (his rule from 21 Sep):** restart = coloured `op nuovo`; advance/again = `bt blu`; Vero green (`bt vd`), Falso red (`bt pr`); right answers green, wrong red (`.giusta/.sbagliata/.spenta`).
- **Reader «today»:** `LET.righe[n]` = text rows of page `n` with `y` = fraction 0..1 and `el[].s` (filled by `disegnaDavvero` once the page is drawn, before `apriScorrimento` resolves).
- **Tests must leave no trace:** snapshot and restore `stato.giocatori/partite/imp/viste` + the 8 game state objects in `finally`; mute `avvisa`; `GIOCHI_PAUSA` = 0 during tests.
- **Games architecture:** one roster + one play list; every game keeps a `pid` so a play/series is one row; the player page is a sub-view (`GIO.giocatore`) — every `vXxx()` starts with
  `if(GIO.giocatore) return vPaginaGiocatore();`; the player bar is replaced in place (`aggiornaBarraGiocatori`) so typed crossword letters survive.
