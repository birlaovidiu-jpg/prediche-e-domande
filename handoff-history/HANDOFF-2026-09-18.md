## ❌ Failed Attempts (this round)

### Assuming a hand-built minimal `.pptx` test file proves the importer works on real files
The first test `.pptx` (v7.52) had explicit `<a:xfrm>` on every shape — unrealistic; real
PowerPoint files rely on layout/master inheritance for standard placeholders. This test file
passed cleanly while the real feature was still broken, giving false confidence. **Lesson**: for
any file-format importer, a synthetic test file that writes *everything explicitly* is not a
sufficient test — it must also cover "the common file omits most attributes and relies on
inheritance," which is usually the *normal* case, not an edge case.

### Trusting IndexedDB blobs to survive across `navigate()` calls in the test browser pane
While testing the lezionario feature, PDF file blobs saved via `salvaAllegato`/`kvSet` vanished
after a full page reload of the test browser tab (`stato.lezionari` metadata survived via
`localStorage`, but the actual PDF bytes — IndexedDB-only — did not). This is a characteristic of
the *test environment* (Claude's Browser pane), not a bug in the app: real users on real Safari
don't reload the whole page between actions. **Lesson**: when testing file-attachment flows in
this pane, re-upload the file within the same page load rather than trusting persistence across a
`navigate()`, and don't mistake this for an app bug.

### Simulating an annotation object by hand without the `dl` field
Building a fake highlight object to test `importaAppuntiAltraLingua()` without `dl` (which
`fineTratto()` sets on every real annotation, `a.dl = LET.lez ? LET.lez.i : ''`) made the import
function silently find nothing, because `daAltri` requires `a.dl` to be truthy. Looked like the
import was broken; it was the test fixture that was incomplete. **Lesson**: when simulating a UI
action's result object for testing, grep for every field the *real* finalization code sets, not
just the ones the algorithm under test directly reads.

## ✅ Working Solutions (key decisions this round)

- **When a heuristic algorithm's "confidence check" (here: matching by sentence, then
  cross-checking with global sentence position) turns out to only be reliable for one of its two
  jobs (finding the right paragraph) but not the other (finding the right point inside it), don't
  patch the confidence check — replace the whole thing with a simpler unit that doesn't have the
  ambiguity.** Words count identically in every language; sentences don't (punctuation
  conventions differ). This is why v7.56's rewrite is simpler *and* more correct than the system
  it replaced, not just a bug fix bolted onto more complexity.
- **Validate a cross-language text-matching fix against real bilingual source files, not just a
  hand-written test paragraph.** The hand-written `9_avvio.js` test (dating back to 11 September)
  never exercised the specific punctuation mismatch that broke the real lezionari — it would have
  kept passing throughout the whole broken period. Real files surfaced the actual failure mode.
- **Keep the old computation path when introducing a new one for saved user data**, gated by a
  version marker on the data itself (`v2`→`v3` here), not deleted. This is now the third time this
  pattern has been used in this file (11 Sept: word-index anchors; 16 Sept: split-paragraph
  anchors; 18 Sept: word-global anchors) — it's the established, working way to evolve this
  particular piece of persisted user data without a migration script.
- **A JS-computed `transform:scale()` needs to be invoked at every place the scaled content is
  rendered**, including places that don't share a JS scope (a `document.write()`'d popup window
  needs its own copy of the scaling function). Missing one render site (the popup, the regia
  preview) isn't caught by testing only the main screen.
- **Publish, then re-verify with a direct `curl` against the live URL** — the publish script's own
  success message is not proof enough on its own; this has been the standing verification method
  for several rounds now and caught nothing wrong this time, but don't skip it.

## ⚠️ Gotchas / Traps

**New this round:**
- **A shape without its own `<a:xfrm>` in a real `.pptx` almost always means "inherit from the
  layout, then the master"** — never treat a missing position as "this shape has no position," or
  most real slides will render empty. Same idea for slide background.
- **`transform:scale()` computed in JS must be re-applied everywhere the scaled DOM is rendered**
  — a `document.write()`'d popup window is a separate JS realm and needs its own copy of the
  scaling function; a small preview box needs its own measurement element if the box itself
  doesn't carry real dimensions (`#rgTela` doesn't, `.rg-mini` does).
- **Word-count is a language-invariant unit; sentence-count is not.** Punctuation conventions
  (colon before a quote, closing-quote-vs-reference ordering) differ enough between Italian and
  Romanian editions of the same lesson that "same number of sentences in this paragraph" is not a
  safe assumption — don't reach for sentence-based matching again for this kind of text.
- **Real annotation objects need `dl` set** (`a.dl = LET.lez ? LET.lez.i : ''`, set by
  `fineTratto()`) for `importaAppuntiAltraLingua()`'s `daAltri` filter to find them — a
  hand-simulated annotation missing this field will make the import silently do nothing.
- **Safari (including iPadOS) needs `dragenter`'s default prevented, not just `dragover`'s**, or
  it can reject a file-drag gesture before `drop` ever fires.

**Carried forward from before this round (condensed — fuller story in `programma-prediche-domande.md`
and older handoffs in `handoff-history/`):**
- Positional ids (`'a'+i`, `'q'+i`) shift if you ever delete/reorder rows in the *source* JSON
  files. Prediche ids are stable (`'pr'+numero`); Cantici and Poesie are **not** — never delete a
  row, only hide via a runtime `Via`/`ViaDef` set.
- `pubblica.py` uses `git worktree` (not `git stash`) to avoid leaving the repo on an orphan
  branch — keep it that way.
- No lookbehind regex, no `??=`/`.at()`/`structuredClone` in app code (old iPad Safari support).
- Before adding any new top-level `const`/`function`, `grep sorgenti/` first — all files
  concatenate into one script via `costruisci.py`, a duplicate declaration kills the app silently.
- The test preview pane doesn't fire `requestAnimationFrame`/scroll events reliably when hidden,
  and renders `height:100dvh` fixed-position pages oddly — don't mistake either for a real bug
  without checking a real device.
- `execCommand('insertOrderedList'/'insertUnorderedList')` can leave an `<ol>`/`<ul>` invalidly
  nested inside a `<p>` — always route list buttons through `eseguiLista()`/`cmdLista()` in
  `5_prediche.js`.
- A `contenteditable` seeded with `''` behaves unpredictably — always seed with `'<p><br></p>'`.
- Service worker caching: a browser that visited the live site before keeps showing old content
  until its service worker updates. GitHub Pages CDN edge lag can also serve stale content for a
  minute or two right after a publish — verify with `curl` from a real terminal.
