## ❌ Failed Attempts / traps (this session)

- **Rewriting a question can silently change which option is right** — happened ~15 times during the grammar pass and was caught only by re-reading question +
  options + key together. Always re-check the key after rewording; never add a «more correct» option.
- **Mass regex fixes on Romanian** mixed cedilla and comma diacritics in the same question → normalise per question to the original's style.
- **«capitolo N» without the book** is also produced by generated questions («in capitolul 8?», «capitolul anterior, 20») — search both languages and all forms.
- **`/tmp/icon_tmp.icns` disappeared** (macOS clears /tmp). Copy the icon from the previous build BEFORE deleting it (recipe below).
- `sleep` in a foreground chain is blocked → use `perl -e 'select(undef,undef,undef,20)'` in the curl loop.
- The random test «trenta presentazioni da venti» was the symptom of identical duplicate questions (see v7.9.8 point 4), not flakiness.
