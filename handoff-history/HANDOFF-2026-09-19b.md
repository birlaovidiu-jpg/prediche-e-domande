## ✅ Working Solutions

- Store the **exact page** of an annotation (`pg`) instead of deriving it from a day-relative offset when the storage key
  (`chiaveNota`, grouped by days recognised in *all* editions) and the page grouping (`pagineDelGiorno`, days of *this*
  edition) can disagree.
- Migrating a default without a flag is impossible to distinguish from a user choice → add an explicit flag (`pagS`) set
  only by the user's palette action; treat old defaults without it as "default".
- Tap-vs-scroll: for a tool that acts on tap, defer the action to `touchend` and cancel if the finger moved >10 px.
- Publish flow: `python3 costruisci.py N` → test in browser (`autoTest()`, run twice: the "599 domande diverse su 600"
  check is a known flaky one) → delete old html → `python3 pubblica.py N` → reapply Finder icon (recipe below) →
  poll `curl` for `VER="N"`.
