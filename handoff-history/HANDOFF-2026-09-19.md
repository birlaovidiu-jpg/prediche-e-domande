  nonsensical anchor** (`gwF:99999`) must still render at its real `a.rr` rectangle, proving the

## ✅ Working Solutions (key decisions this round)

- **When a piece of on-screen state is guaranteed stable once created (a highlight's rectangles on
  a PDF page, which never reflows), never recompute it from a derived/approximate value at render
  time "just in case" — only fall back to the derived value when the direct one genuinely isn't
  available** (a different edition, or old data that never recorded the direct value). Recomputing
  "for safety" when a stable direct value already exists is exactly how v7.67's bug happened: the
  anchor recompute was meant for the OTHER edition, but ran unconditionally, including for the
  edition where it could only ever make things worse.
- **A greedy min-fill (assign the next item to whichever bucket currently has the fewest, counting
  pre-existing data too) balances three unequal groups better than a round-robin split of only the
  new items** — used to fix the chihadetto difficulty-balance regression after deduping introduced
  an uneven number of drops per level.
- **When asked for a large amount of "true story" content under a real sourcing constraint, write
  new original prose about well-documented facts/people instead of translating or copying any
  specific existing text** — this was already the pattern the original 183 Esperienze used
  (real people, original wording) and sidesteps the copyright question rather than needing to
  litigate it per-source; reused deliberately for the 109 new ones this round.
- **Publish immediately after each tested round now** (new standing instruction from Ovidiu this
  session), verified live via `curl` each time, version number bumped every publish even when two
  rounds land close together (avoid re-publishing the same version number twice with different
  content — did that once this round, by mistake, then corrected to a fresh number).

## ⚠️ Gotchas / Traps

**New this round:**
- **`costruisci.py`'s version argument has no safe default worth relying on** — `sys.argv[1] if
  len(sys.argv)>1 else '1.0'`. Forgetting to pass a version number silently builds
  `Prediche_e_Domande_v1.0.html` instead of erroring; happened once this round, caught only
  because the printed filename looked wrong.
- **A "confidence check" fallback (try the derived/approximate value, fall back to the direct one
  only if the derived one comes back empty) is not the same as "only use the derived value when
  the direct one is genuinely unavailable."** `rettDi`'s old logic fell into the first, weaker
  pattern — it fell back to `a.rr` only when `rettDaAncora` returned *nothing*, not when it
  returned a *wrong but non-empty* answer, which is exactly what happened here. When a direct,
  known-correct value exists for a specific case, gate on that case explicitly, don't rely on the
  fallback branch of a "try the clever thing first" pattern to catch it.
- **The chihadetto game's real dedup key is `(language, quote text, speaker)`, not verse
  location** — two different Bible verses (e.g. a saying repeated across two Gospels) can produce
  what the game considers the identical question. Any future extraction script touching this data
  must dedupe on that key, and any difficulty-balancing must happen **after** that dedup, not
  before, or the difficulty thirds drift.
- **This app is genuinely public** (published to GitHub Pages every round now, automatically) —
  don't accept "it's just for private/personal use" as a reason to relax a copyright judgment call;
  correct that assumption if it comes up, as it did this round.

**Carried forward from before this round (condensed — fuller story in `programma-prediche-domande.md`
and older handoffs in `handoff-history/`):**
- Positional ids (`'a'+i`, `'q'+i`) shift if you ever delete/reorder rows in the *source* JSON
  files. Prediche ids are stable (`'pr'+numero`); Cantici, Poesie and Esperienze are **not** —
  never delete a row, only hide via a runtime `Via`/`ViaDef` set, and always **append** new
  entries via a separate extension file merged in `costruisci.py`, never insert into the middle of
  an existing array.
- `pubblica.py` uses `git worktree` (not `git stash`) to avoid leaving the repo on an orphan
  branch — keep it that way.
- No lookbehind regex, no `??=`/`.at()`/`structuredClone` in app code (old iPad Safari support).
- Before adding any new top-level `const`/`function`, `grep sorgenti/` first — all files
  concatenate into one script via `costruisci.py`, a duplicate declaration kills the app silently.
- The test preview pane doesn't fire `requestAnimationFrame`/scroll events reliably when hidden,
  renders `height:100dvh` fixed-position pages oddly, and can show a **stale screenshot** right
  after a navigation/state change — re-screenshot or check the DOM/JS state directly before
  concluding something didn't render.
- Service worker caching: a browser that visited the live site before keeps showing old content
  until its service worker updates. GitHub Pages CDN edge lag can also serve stale content for up
  to a minute or two right after a publish — verify with `curl`, polling a few times.
