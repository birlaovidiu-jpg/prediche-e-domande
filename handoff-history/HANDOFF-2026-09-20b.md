## ❌ Failed Attempts (this session — do not redo these)

### Guessing what «due file» meant in the backup
- **What:** I hypothesised dated names piling up (`Copia … <date>.json`) or a share+download double save.
- **Why it failed / what it really was:** he answered my multiple-choice question in free text («aggiunge un file di
  testo come vedi») and then sent a Finder screenshot: **`Testo.txt` next to the JSON**. `navigator.share({files,title})`
  makes iOS save the `title` as a text file. Fix = pass only `{files:[file]}` (also in `condividiLez`). **Lesson:**
  when a request is ambiguous, ask ONE targeted question and let him send a screenshot.

### «The toolbar moved slightly left» is not a v7.75 regression
- `posBarraLet()` read the left edge of the FIRST `.let-foglio`. At first open the undrawn placeholders are laid out
  before the 10 px scrollbar appears, so they are 10 px wider than drawn pages → bar 5 px left of the visible page
  (measured 23 vs 28). Fix: use the first sheet with `LET.pagine[n]` set (already drawn). **The root cause
  (placeholder width ≠ drawn width, pages jump 10 px when drawn) was deliberately NOT changed.**

### Rotation handler v1 compared `largSchermo()`
- On desktop the scrollbar changes `#letArea.clientWidth` by 10 px, so every `resize` looked like a width change and
  re-laid everything out. Now it compares `window.innerWidth` (`LET._largLay`), so keyboard/height-only resizes do nothing.

### «Colours are not remembered» — the real cause was the startup self-test
- `autoTest()` (runs at EVERY launch) called `setCol('#123456')` while `LET.colori` was still the default object
  (only `apriLez` merges the saved ones) and saved it → **all four tool colours reset to red, highlighter dark blue,
  on every launch.** Also: with the hand tool active, picking a colour in the note dialog changed the *highlighter*
  colour, and saving an existing note recoloured it with the highlighter colour. All fixed; the test now snapshots and
  restores state and mutes `avvisa`.

### Games layout v1 clipped the fixed landscape pages
- **What:** level as a `.scelta` card in the filter grid + a separate full-width players bar.
- **Why it failed:** +2 rows in `body.gio-fissa` pages (they use `overflow:hidden`): Memoria 10 pairs cut by 122 px, X e O
  finished by 379 px. **Fix:** level buttons live in the SAME row as the players; `body.gio-fissa .gio-pagina` now
  `overflow-y:auto`; X e O finished shows grid and prizes side by side; Memoria card `min-height:clamp(58px,9.5vh,100px)`.
- **Also:** a 4-column filter grid was considered and dropped (the level card needs ~300 px).

### Test-environment traps (not product bugs)
- Built-in browser: `resize_window` **does not fire `resize`** → `window.dispatchEvent(new Event('resize'))`.
- Screenshots fail with «pane not displayed» → `preview_start` with a `url` opens a visible tab; do resize → wait → screenshot
  **sequentially** (parallel calls return stale frames).
- In a second tab the coordinate `left_click` landed at ~1.9× the intended point (even with `ref`) → use `el.click()` in JS.
- The tool's `key Return` is not `event.key==='Enter'`; dispatch a synthetic `KeyboardEvent('keydown',{key:'Enter'})`.

## ✅ Working Solutions

- **Lezionario selections (v7.76):** colours per tool in `stato.imp.coloriLettore` (never touched by the self-test now);
  `stato.imp.carattereLettore` saved when the font changes; `stato.imp.grandezzaLettore` saved **only if he moved the

- **Home on return:** only in the installed app; saves the open sermon (`salvaTesto(id,true)`), closes projection/regia/reader/
  modals through their canonical closers, then `vai('home')`.
- **Rotation:** debounce 220 ms, re-lay out with `apriScorrimento`/`mostraPag`, keep the reading position as a fraction
  of the page at the top of the view.
- **Games architecture:** one roster + one play list; every game keeps a `pid` (instance key) so a play/series is one row;
  the player page is a sub-view (`GIO.giocatore`) — every `vXxx()` starts with `if(GIO.giocatore) return vPaginaGiocatore();`;
  the bar is replaced in place (`aggiornaBarraGiocatori()`, outerHTML) so typed crossword letters survive.
- **Tests must leave no trace:** snapshot `stato.giocatori/partite/imp` + the 8 game state objects (`JSON` copy) and restore in
  `finally`, mute `avvisa` (pattern: see the players block in `autoTest`).
